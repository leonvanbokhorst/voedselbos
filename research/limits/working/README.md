**Mark conventions.** The repository uses **[D]** documented, **[C]** claimed, **[I]** inferred, **[U]** not established, **[P]** commissioner-provided. Each working file states its own read-depth conventions (`FT`/`ABS`/`SNIP`).

**Delegation record.** Two bounded researchers on disjoint source families and disjoint output files, each told to retrieve rather than recall, record metadata and read depth, hunt unflattering evidence and null findings, return "not established" rather than fill a gap, not read the other line's output, and not spawn further agents. Neither ran `git`; neither touched a file outside this directory.

**Where the note overrules the working files — deliberately.**
1. **A date conflict left open.** The delegated regulatory line's third-party status page says "eind 2027" for the SMP; the municipality's own collegebrief says "medio juli 2027", use from Q3 2027. The note carries the municipal date as primary and the aggregator as secondary `[C]`.
2. **Two numeric corrections in verification.** The literature line reported local atmospheric N deposition as 7 kg N ha⁻¹ yr⁻¹ (De Frenne et al. report **22.7** for the study area, 7 being a separate figure the paper also cites) and omitted the **10–70 kg N** mowing-removal range while quoting only the P range. Both were corrected against the author's repository copy, which the Lead read in full.
3. **One qualification added.** Banks & Bryant's −35%/−41% figures are a *single-pass displacement* effect measured with the dog **on a lead**; the note reports the authors' own caveat that long-term impacts "may be small", and states that a leash duty therefore addresses pursuit and ranging, not presence.
4. **One over-assertion removed.** The note does **not** describe dog disturbance and dog nutrient loading as "additive": no retrieved study separates them, and the note says so.
5. **One snippet refused.** A Dutch recreation-capacity sentence surfaced only as a search snippet behind a 403. It appears in neither the note nor the source register as evidence.

**What is not here.** No stakeholder was contacted; no login, paywall, CAPTCHA or Cloudflare challenge was bypassed; no robots.txt exclusion needed to be relied on; no field survey; no site allocation; no legal advice.
