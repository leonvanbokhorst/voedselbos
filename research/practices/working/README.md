**Mark conventions.** The repository uses **[D]** documented, **[C]** claimed, **[I]** inferred, **[U]** not established, **[P]** commissioner-provided. The delegated files use the same four repository marks in `cases-gestel.md` and `cases-strijp.md`; `contrasts.md` uses its own `[FT]/[A]/[R]` read-depth marks alongside them. `lead-cases.md` uses the repository marks. Read each file's header before citing from it.

**Delegation record.** Three bounded researchers on disjoint files, each told to retrieve rather than recall, mark read depth, hunt unflattering evidence, return "not established", and not to spawn further agents. The Lead re-read six sources in full (listed in `../note.md` §11) and found one discrepancy and one same-copy duplication; the remaining material is reported from the delegated retrievals, with URLs in `../sources.md`.

**What is not here.** No stakeholder was contacted; no login, paywall or CAPTCHA was bypassed; no participant's private words appear; nothing here ranks communities or extracts personal stories.
